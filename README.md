# Ahmet Taha Albayrak — Portfolio

Bilingual personal portfolio for Ahmet Taha Albayrak, built with Next.js,
React, TypeScript and Tailwind CSS. The project is exported as a fully static
site and deployed to GitHub Pages.

## Local development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run verify
```

The verification command runs linting, TypeScript checks, the production build,
and static-export tests. `npm run build` creates the deployable site in `out/`.
Pushing `master` runs the GitHub Pages deployment workflow.
